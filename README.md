# 两雄争霸 ⚔️

给弟弟（陈大至）做的小游戏：攒 R → 买装备 → 打败姐姐陈小柔！

## 🎮 在线玩

点击这里直接开玩：**https://wk1835429772-prog.github.io/liangxiong-zhengb/**

> 存档存在浏览器本地（localStorage），换设备/清缓存会重新开始。

## 📖 玩法

- **赚钱**：按时睡觉 5R / 拿快递（按重量：轻 1R · 中 3R · 重 5R，每天 3 次）/ 扫地 3R / 按时吃饭 3R；家长设置里还能自定义任务
- **商店**：火枪 10R · 龙王大炮 30R · 龙王之盾 12R · 龙王盔甲 25R · 皇帝盔甲 40R · 战马 15R · 复活药水 8R · 玉杯 1R
- **武器升级**：火枪 / 龙王大炮每级 2R，最高 5 级，伤害随等级成长（火枪 15→27，大炮 35→55）
- **对战**：回合制出牌，AI 模式 + 姐弟双人热座；集齐 5 个玉杯召唤龙王，开战先轰 50 点

## 🖍️ 美术

全部原画出自**陈大至（弟弟手绘）**——铅笔线稿：两雄对决标题、应用商店清单、盔甲兵器页、药水页。
游戏内主视觉由 AI 以弟弟的画为底稿重绘成精致卡通版（三角洲枪炮 + 奥特曼能量 + 中华武将风格），原稿以图鉴形式保留在商店底部。

## 🚀 本地运行

下载 `两雄争霸.html` 和 `game/` 目录放在同一文件夹，双击 HTML 即可玩；或直接克隆本仓库：

```bash
git clone https://github.com/wk1835429772-prog/liangxiong-zhengb.git
cd liangxiong-zhengb
start 两雄争霸.html   # Windows
```
