## 1. 图 1 — 标题页 + 两雄对决

**原始文件名**：`微信图片_20260828225748_5632_47.jpg`
**方向**：拍摄时横放，文字自下而上 → **顺时针旋转 90°** 后，「两雄争霸」四字位于页面顶部。

### 画了什么
- **标题文字**：铅笔手写 **「两雄争霸」** 四个大字，写在横线本最上方几行，笔画用力、有明显铅笔压痕。
- **两个主体人物**（旋转后并排在中下方）：造型几乎对称，各由
  - 顶部一个「自/冒」形的**头盔**（有横向缝/观察孔），
  - 一个**长方形躯干**（像穿了的盔甲/胸甲，里面还写了字或画了纹样），
  - 细线条的**手臂和双腿**（火柴人式四肢），
  - 一根斜向上伸出的**长兵器**（长枪 / 长刀），两人的兵器在空中交叉。
  - 这两个人就是「两雄」——**陈大至 与 陈小柔** 穿盔甲对战的形象。
- **右侧一个较小的人物**：圆头（脸上是叉/圈状的简笔五官），身体上写着类似「王」的字，双腿张开。可能是 **龙王**、被击败的敌将，或弟弟给自己画的 Q 版标记?。
- **符号**：人物旁有 `X` 形划痕和对勾形笔迹，像是表示「打中了 / 淘汰」。
- **左侧**有一片很淡的擦除痕迹（早期草稿）。

### 主色调 / 画风 / 纸张
- 全图只有**铅笔灰**一种颜色，未上色；纸张是**横线笔记本**（左上角有 `No.` / `Date` 栏），背景为绿白格子布。
- 画风：**火柴人 + 方块盔甲**的儿童简笔，线条直、转折硬，靠方框表达「穿着盔甲」。

### 建议放进游戏哪里
| 位置 | 理由 |
|---|---|
| **主菜单标题 / 封面横幅**（首选） | 页面上方就是手写的「两雄争霸」四字，是游戏标题最正宗的手写出处，可直接裁出来当标题字，比印刷体更有童趣和真实感。 |
| **对战界面两侧的战斗形象** | 两个对称的盔甲武士天然对应「陈大至 vs 陈小柔」，可分别裁切放到战斗区左右当双方小人。 |
| **开场/胜利动画的装饰** | 交叉的长兵器 + `X` 记号有「交锋、击倒」的叙事感。 |

**技术提示**：这张纸面阴影最重（左侧偏暗），建议先 `灰度 → 提升对比度/阈值`，再用 `mix-blend-mode: multiply` 叠在浅色底上，横线与阴影会被压掉大半。

## 6. 给集成方 AI 的使用提示

1. **先旋转**：图 1、2、4 需**顺时针 90°**；图 3 原样。
2. **去纸纹**：铅笔线稿建议 `filter: grayscale(1) contrast(2.2) brightness(1.15)` + `mix-blend-mode: multiply`，或直接叠在米黄/横线纸底纹上，保留「弟弟的笔记本」质感。
3. **按行裁切**：图 2、3、4 每行是「图标 | 名称 | ¥价格」三栏，图标在行首方框内，裁方框即可当 `icon`。
4. **保留童趣**：不要重画成矢量图，错别字与歪线条是这份素材的价值所在；建议在 UI 上标注「美术：陈大至」。
5. **优先落地顺序**：① 图 1 标题字 → 主菜单；② 图 3 盔甲小人 → 战斗形象换装；③ 图 2/4 图标 → 商店与道具栏；④ 新增道具（弓箭/战船/毒药等）作为后续扩展。
