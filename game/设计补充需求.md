# 《两雄争霸》设计补充需求（master 2026-08-28 补充）

> 给第二轮集成使用。第一轮只负责把弟弟的 4 张画原样结合进 HTML；第二轮按本文件升级视觉设计。

## 1. 设计元素方向（master 原话整理）

- **枪炮**：弟弟喜欢三角洲行动（Delta Force）里的枪械和炮火——武器、攻击特效往现代枪炮/炮塔方向靠。
- **奥特曼**：弟弟喜欢奥特曼——角色要有"变身/能量"感：光效、能量条、光线攻击、闪亮变身、怪兽/机甲化敌人。
- **中华上下五千年**：弟弟最近在看这套插画书——加入中国历史/神话元素：武将盔甲、帝王、龙、古代战场、旗帜、长城、弓箭兵阵。

## 2. 插画升级要求

弟弟的画是底稿和灵魂，不要丢掉；但要在它的基础上**重绘出更精致的版本**：

- 保留：构图、物品清单、两个武士对峙、龙王大炮、玉杯等核心创意。
- 升级：线条更干净精致、上色（暖色卡通渲染）、加光效和纹理。
- 实现方式：优先用 **SVG/CSS 在 HTML 内精细重绘**（矢量、清晰、可控、不依赖外部文件）；如果 qoder 环境有图像生成能力也可以用，但没有就 SVG。
- 童趣保留：可以保留手写感的圆润笔触，但整体要比铅笔草稿精致一个档次。

## 3. 具体落地建议

| 位置 | 现在的样子 | 升级方向 |
|---|---|---|
| 主菜单标题 | 手绘「两雄争霸」图 | 重绘标题：两个武士（一个橙金=陈大至、一个深蓝=陈小柔）穿中国武将盔甲+现代枪炮元素，中间「VS」带能量光效，标题字可保留手写感但更精致 |
| 战斗区 | 圆点小人 | 双方换成精致立绘/盔甲武士，攻击时加枪炮火光或奥特曼式光线特效 |
| 龙王大炮 | 手绘大炮 | 重绘成"中国龙 + 现代巨炮"混搭，放大招时有能量蓄力光效 |
| 商店图标 | 手绘清单图标 | 每个商品重绘成精致图标：枪炮类写实一点、盔甲类有历史插画质感、药水类透明瓶子带发光液体 |
| 玉杯 | 手绘奖杯 | 重绘成金玉质感的奖杯/圣物，带光晕 |
| 战马/战船 | 手绘 | 重绘成古代武将坐骑/楼船，可加旗帜和龙纹 |

## 4. 硬性约束（延续第一轮）

- 禁止改动 JS 游戏逻辑（数值/回合/商店买卖/任务/存档/战斗判定/物品数据）。
- 价格沿用 HTML 现有数值。
- 功能必须完好：开战、商店、任务、存档都要能用。
- 图片/素材引用用相对路径（game/xxx），双击 HTML 即可玩。
- SVG 可直接内嵌 HTML（推荐），或放 game/ 目录。
- 最后用 node 校验 JS 语法，列出改动清单，口头总结 3-5 句话。

## 5. 游戏机制补充需求（master 2026-08-28 追加，**已批准改动 JS**）

> 注意：本节与第 4 节不同——master 明确追加了这些**新机制**，属于本轮任务的一部分，
> 允许改动 JS 游戏逻辑（武器升级、任务系统）。除本节内容外，其余 JS 逻辑仍保持不动。

### 5.1 武器升级系统

- 武器可以升级：**每升 1 级花 2R**，**最高 5 级**。
- 等级影响武器威力（攻击力按等级提升，具体公式自定但要合理、可显示）。
- UI 要求：商店/背包里显示武器当前等级（如 Lv.3/5），升级按钮显示花费（2R），
  金币不足时按钮置灰；升级成功后给一点视觉反馈（闪光/提示文字）。
- 升级是永久的，存档要保存武器等级。

### 5.2 任务系统扩展（赚 R 途径）

现有任务（按时睡觉 5R）保留，新增：

| 任务 | 奖励 | 说明 |
|---|---|---|
| 按时睡觉 | 5R | 已有，保留 |
| 拿快递 | 1-5R | **按重量**：轻 1R / 中 3R / 重 5R（可随机或按当天物品分级，界面要显示本次重量和对应奖励） |
| 扫地 | 3R | 固定 3R |
| 按时吃饭 | 3R | 固定 3R |

- 任务列表在游戏里展示全部任务和奖励；完成后按规则发 R。
- 存档记录任务完成状态；数值沿用 master 给的口径，不要自行改价。
